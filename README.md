# スプレンダー ゲームシミュレーター

このプロジェクトはボードゲーム「スプレンダー」をシミュレートします。ランダムエージェントと2人用のシンプルなゲームループが含まれています。

## プロジェクト構成

- `src/` - ゲームロジックとメインスクリプト
- `data/` - カードや貴族のCSVファイル（現状のコードでは未使用）

## 実行方法

1. 依存パッケージのインストール:
   ```bash
   pip install -r requirements.txt
   ```
2. メインスクリプトの実行:
   ```bash
   python src/main.py
   ```

## 必要条件
- Python 3.8 以上

## 備考
- 現在の実装では `data/` ディレクトリ内のCSVファイルは使用していません。
- デモ用にランダムエージェントでゲームが進行します。
